# Marfim protocol contract tests (Dart)

Client-side contract tests for the Marfim gateway protocol v1. They
consume the SAME canonical fixtures the Rust gate **G11** enforces
(`fixtures/protocol/*.json`, regenerated byte-identically from
`marfim_gateway::protocol::fixture_bytes()`). See `docs/PROTOCOL.md`.

## Run

```sh
cd contracts/dart
dart pub get
dart test
```

The fixture paths resolve relative to this package (`../../fixtures/protocol/`),
so run `dart test` from this directory.

## Status

The Dart SDK is NOT required for the Rust gates — G11 covers the fixture
regeneration. These tests execute wherever a Dart SDK exists (developer
machines, and the mobile CI job that lands with W4.4). They are written
for Dart 3 with the single `test` dev-dependency.
