# Example Skill

## When to activate
When the user asks for a demonstration of Marfim's skill system.

## Workflow
1. Explain that skills live in `.marfim/skills/<name>/SKILL.md` (project) or
   `~/.marfim/skills/<name>/SKILL.md` (global).
2. Show that only `name` + `description` enter the system prompt; the body
   loads on demand via the `skill` tool (progressive disclosure — ECC context
   economics).
3. Note compatibility: `.claude/skills/` directories are honored too (Oh My Pi
   cross-harness doctrine).
