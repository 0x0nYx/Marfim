# Port ledger — what is differentially ported, and what is not

This file replaces the old PARITY.md (whose `[x]` marks were aspirational
rather than verified). The rule here is simple: **a module counts as
ported only when committed JSONL fixtures — generated by running the
Node oracle under node — replay byte-exact through the Rust port.**

Oracle: Node `marfim` v1.2.0 (`archive/node-v1.2.0` tag; working copy in
the preservation bundle). Oracle census: 597 files / 134,920 LOC
(`src/intel` 73,025; `src/core` 10,152; `src/web` ~3,215; `test/intel`
20,240; skills 13). Eval data contains sealed sets that are NEVER used
for tuning.

Determinism doctrine: same input order, seeded RNG only, no wall-clock,
no HashMap iteration in output-affecting paths. Ints/strings byte-exact;
floats exact for elementary ops, <=1 ulp for transcendentals.

## Faculty integration

`marfim-core::faculty` defines the five hook points (pre_model,
pre_tool, pre_compaction, post_step, idle_propose); every call is
published as a `faculty_hook` event. `marfim-brain::faculty::
LearningFaculty` wires the ported learners: ADWIN drift over step
outcomes, conformal risk, per-model regret audit, bounded salience
protection before compaction, propose-approve idle surface. Learning
state: local, bounded, inspectable (`why()`), reversible (`forget()`).

## Ported to Rust at the harness level (behavior tests, not fixtures)

The harness surface was reimplemented clean-room with its own
regression tests (loop invariants INV-01..10, D1..D24, wire goldens in
`marfim-core`): agent loop + steering/verify/compaction, providers
(anthropic + openai-compatible wires + mock), router with failover and
optional bandit routing, journal, permissions/shellparse, sandbox
(Landlock/Seatbelt), MCP/LSP/ACP/serve surfaces, session actor, TUI.

## Not yet ported from the oracle (honest remainder)

The oracle's ~40k LOC of LLM-coupled intelligence (agent orchestration,
memory graphs, learn/nlhistory loops, dispatch/executor, devflow/
diagnostics/genius/issues domains, web app) is NOT in this release. The
harness exposes the Faculty surface those systems plug into; the oracle
tree stays preserved for the next porting waves. Nothing in this list is
faked: there are no stubs pretending otherwise.

**Regenerability note (2026-11-07, ledger row W13):** the preserved oracle
tree is NOT reachable from this repository — `git ls-remote --tags origin`
returns only `v1.0.0` (a Rust-workspace commit) and there is no `archive/*`
tag or Node tree on the remote. The committed fixtures in
`fixtures/intel/*.jsonl` are therefore a FROZEN record: they replay
byte-exact in CI, but they cannot be regenerated or extended until the
owner pushes an `archive/*` tag (docs/OWNER-INPUT.md row 3). W13 stays
BLOCKED on that input.
