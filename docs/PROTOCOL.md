# Marfim Gateway Protocol v1

The wire contract of `marfim serve`: HTTP/1.1 + SSE on top of a bearer
token. The canonical machine-readable shapes live in
`fixtures/protocol/*.json` — regenerated byte-identically from
`marfim_gateway::protocol::fixture_bytes()` and enforced by gate **G11**
(`cargo test -p marfim-gateway --test protocol_fixtures`). This document
is the prose form of the same contract; when the two disagree, the
fixtures win and this file is stale.

Dart contract tests (mobile/Flutter client side) live in
`contracts/dart/` and consume the same fixture files.

## Transport and security posture (fail-closed)

**Transports (W2.3)**: `marfim serve` speaks the same protocol over
three listeners — plain TCP (`--host/--port`), TLS over TCP
(`--tls-cert <pem> --tls-key <pem>`, rustls, TLS 1.3/1.2, ALPN
`h2`/`http/1.1`; boot fails closed on any PEM problem), and a unix
socket (`--unix <path>`, chmod 0600, stale socket reused, a non-socket
file at the path is never removed). TLS does not apply to unix sockets.
The bearer token is mandatory on every transport.

- **Bearer token mandatory** on every route, including `/healthz`:
  `Authorization: Bearer <token>`. `--token <t>` or an auto-generated
  token printed once at startup. Compared in constant time.
- **Host/Origin validation** (DNS-rebinding defense): the `Host` header
  and any present `Origin` must name an allowed host (bound host +
  loopback aliases). Violations get `403` before the body is read.
- **Limits**: 1 MiB header buffer, 1 MiB body cap (declared oversize →
  `413` unread; real oversize → `413`), header-phase and body-phase
  timeouts (slowloris defense), SSE pings + hard stream lifetime
  (default 3600s, then `stream_deadline`).
- Nothing a client sends aborts the process: malformed garbage kills
  only its own connection; the listener keeps serving.
- fs/git/mcp route behavior is **injected** by the embedding surface;
  an unwired route answers **`501`** (`route not wired by the embedding
  surface`) — the transport never fabricates behavior. All fs tool
  routes run through the real tool host: hooks → permission engine
  (deny > ask > allow) → sandbox → dispatch. Serve is unattended: asks
  are **denied** (D14 fail-closed), never parked.

## Envelope

Every response body is a single JSON object (`content-type:
application/json`), error or not: `{"error": "..."}` on failure.

**SSE streams** (`content-type: text/event-stream`,
`cache-control: no-cache`):

- Every **data frame** carries `id: <seq>`:
  `id: 7\ndata: {"event":"assistant_message",...}\n\n`
- Ring streams (`/v1/events`, `/v1/sessions/:id/events`): `seq` is the
  session's monotonic event number from the per-session ring (cap 4096).
  Resume with `Last-Event-ID: <seq>` (header) or `?lastEventId=<seq>`
  (query) — the server replays **exactly** the retained entries with
  `seq > last`, then continues live. No duplicates, no silent gaps: a
  bus overrun becomes an explicit
  `data: {"event":"lagged","dropped":N}` frame (transport) or a
  `ring_lagged` ring entry (pump), so the client's seq space is
  contiguous.
- Prompt streams (`/v1/prompt`, `/v1/sessions/:id/prompt`) stamp ids
  from a per-stream counter; resume is not meaningful for a single-turn
  response — reconnect by re-issuing the prompt or by watching the
  ring stream.
- Keepalive: `: ping` comments on idle (default 15s). Comments carry no
  `id:` — they are not events.
- Terminal markers: prompt streams end with
  `{"event":"turn_end","stop_reason":"end_turn|error|..."}`; all streams
  end at the hard lifetime with `{"event":"stream_deadline"}` (id-less
  on ring streams).

Event payloads inside data frames are the bus events serialized by
`Event::to_json_line()` — the full catalogue with exact bytes is
`fixtures/protocol/events.json` (18 kinds: `session_started`,
`turn_started`, `model_selected`, `assistant_message`, `thinking`,
`stream_delta`, `tool_call_started`, `tool_call_result`,
`approval_requested`, `approval_resolved`, `usage`, `compaction`,
`verify_started`, `verify_finished`, `turn_end`, `error`,
`faculty_hook`, `actuation`).

## Routes

Canonical request/response shapes: `fixtures/protocol/routes.json`.
All routes require the bearer token.

| Method | Path | Purpose |
|---|---|---|
| GET | `/healthz` | liveness + version |
| GET | `/v1/tools` | real tool catalog (name/description/schema) |
| GET | `/v1/sessions` | snapshot listing |
| POST | `/v1/sessions` | create (`title?`, `resume?`) → 201 snapshot |
| GET | `/v1/sessions/:id` | one snapshot |
| DELETE | `/v1/sessions/:id` | close (in-flight turn cancelled first) |
| POST | `/v1/prompt` | run a REAL turn (SSE); `session_id?` selects |
| POST | `/v1/sessions/:id/prompt` | the same, session in the path |
| POST | `/v1/sessions/:id/steer` | queue mid-turn steering → 202 |
| POST | `/v1/sessions/:id/cancel` | cooperative cancel |
| POST | `/v1/sessions/:id/undo` | drop last completed turn (409 if none) |
| POST | `/v1/sessions/:id/rewind` | drop last N turns (`turns`) |
| POST | `/v1/sessions/:id/fork` | journal copy → 201 `ForkOutcome` |
| GET | `/v1/sessions/:id/events` | ring SSE for one session |
| GET | `/v1/events` | ring SSE for the default session |
| GET | `/v1/approvals` | pending approval jobs |
| POST | `/v1/approvals/:id` | resolve: `allow\|allow_once\|allow_always\|deny` |
| GET | `/v1/config` | redacted config view (no credential material) |
| POST | `/v1/fs/read` | `{path}` → `{"tool":"Read","output":...}` |
| POST | `/v1/fs/list` | `{path}` → `{"tool":"LS","output":...}` |
| POST | `/v1/fs/write` | `{path, content}` → `{"tool":"Write",...}` |
| GET | `/v1/git/status` | read-only status through the real backend |
| POST | `/v1/git/diff` | read-only HEAD↔worktree diff |
| POST | `/v1/git/log` | `{limit?}` (≤200) commit listing |
| GET | `/v1/mcp` | connected MCP servers + registered tool names |
| POST | `/v1/terminals` | spawn a PTY session `{command, args?, cwd?, rows?, cols?}` → `{id}` |
| GET | `/v1/terminals` | session list (id/command/alive/exit/bytes/age) |
| POST | `/v1/terminals/:id/input` | `{text}` → raw stdin bytes (no shell parsing) |
| POST | `/v1/terminals/:id/resize` | `{rows, cols}` → SIGWINCH + grid resize |
| GET | `/v1/terminals/:id/screen` | plain-text screen snapshot + alive/exit/cursor |
| DELETE | `/v1/terminals/:id` | kill + close the session |

Unknown route → `404 {"error":"not found"}`; known path with wrong
method → `405`. Session command errors: missing session `404`, missing
or empty text/turns `400`, refused rewind/undo `409`, actor gone `500`.

### Terminal surface (W3.1)

Terminals are **injected like fs/git/mcp**: the embedding wires the
`terminals` handler through the REAL Terminal tool, so every spawn/write
flows hooks → permission engine → sandbox → dispatch and an unwired
gateway answers `501` honestly. Sessions are bounded (16 per surface,
cap errors name the remedy), each carries its own PTY (the child sees a
tty, `isatty()` true) and a vt100 grid; output bytes land in a bounded
ring (64 KiB, drop-oldest with an explicit `[marfim-term: older output
dropped (ring cap)]` marker in the drained text); exited sessions keep
their final screen readable for 60s, then are reaped lazily.

## Config redaction

`GET /v1/config` exposes provider/model/routing/permission-mode/sandbox
level/limits/cwd/mcp server NAMES. Credential material (API keys, env
values, tokens) is **structurally absent**: redaction happens in the app
layer (`redacted_config_view`), the gateway never holds secrets, so no
transport bug can leak them.

## Versioning

`protocol: "1"` is pinned in `fixtures/protocol/routes.json` and
`events.json` (PROTOCOL_VERSION). Additions are new optional fields or
new routes; breaking changes bump the version and require a new fixture
generation plus a CHANGELOG entry.
